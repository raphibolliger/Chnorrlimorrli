# Chnorrlimorrli

Webseite und Shop für das Freiämter Kinderbuch «Chnorrlimorrli».

- Frontend: Angular, Tailwind CSS, GitHub Pages
- Backend: Supabase (Datenbank, Auth, Storage, Edge Functions)
- Zahlung: Stripe Checkout
- Mailversand: Azure Communication Services

Anforderungen und Planung: Issue #1 und die zugehörigen Sub-Issues.

## Entwicklung

```bash
npm install
npm start
```

Details zu Konventionen und Deployment stehen in `AGENTS.md`.
